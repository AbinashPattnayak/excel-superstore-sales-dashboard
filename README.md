# Excel-superstore-sales-dashboard
Interactive Excel dashboard analysing sales, profit, and regional performance using a public Superstore dataset.

**1. Project Overview**

This project focuses on analyzing retail sales data and presenting key business insights through an interactive Excel dashboard.
The dashboard helps understand sales performance, profitability, and trends across different time periods, regions, and product categories.

The objective of this project is to demonstrate Excel data analysis, visualization, and dashboarding skills using real-world structured data.

**2. Dataset Information**

Dataset Name: Sample Superstore Dataset

Source: Tableau Public (Sample Dataset)

Dataset Type: Public / Educational

Sheets Available: Orders, Returns, People

Sheet Used for Analysis: Orders

 This dataset is publicly available and widely used for learning and portfolio projects.
Credit is given to Tableau for providing the Superstore sample dataset.

**5.Business Insights**

Sales show a consistent upward trend over time, indicating overall business growth.

Certain regions contribute a significantly higher share of total sales compared to others.

Some product categories generate high sales but relatively lower profit margins, highlighting the impact of discounts and costs.

Profit margin does not always increase with sales, showing the importance of profitability analysis.

Monthly trends reveal seasonal patterns, with specific months performing better in terms of revenue and profit.

Interactive slicers enable quick, user-driven analysis for better decision-making.

**6. Conclusion**

This project demonstrates the ability to transform raw sales data into meaningful insights using Excel.
The dashboard is designed to be clean, interactive, and business-friendly, making it suitable for portfolio presentation and interview discussions.
